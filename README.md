# SohdCode Mobile

Native Android coding app by **Ahamd Murad**.

Kotlin, Jetpack Compose, Supabase Auth, sandboxed JavaScript, multi-provider AI.

This is not Flutter, React Native, Expo, or a WebView shell.

## Open in Android Studio

1. Install Android Studio and an Android SDK (compileSdk 35, minSdk 26).
2. Copy `local.properties.example` to `local.properties`.
3. Set `sdk.dir` to your local Android SDK path.
4. Sync Gradle and run the `app` configuration.

Public Supabase URL: `https://qzwpjozaljddxtmprvrt.supabase.co`

Use only the publishable/anon client key. Never add the service-role key.
